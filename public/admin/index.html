Maps

Each map is a canvas. Place one or more images on it, then draw hitboxes that link to other maps and annotations with notes. The default map opens first in the viewer.

Image types

Types decide which images fade. Focus: fades while another image is focused. Zoom-reveal: fades as you zoom into it, revealing what's behind. Each image on a map can also be set to always or never fade.
