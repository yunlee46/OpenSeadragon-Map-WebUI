Maps

Each map is a canvas. Place one or more images on it, then draw hitboxes that link to other maps and annotations with notes. The ★ default map opens first in the viewer. Drag maps into folders to organise them; right-click for more.

Image library

Image types

Types decide which images fade. Focus: fades while another image is focused. Zoom-reveal: fades as you zoom into it, revealing what's behind. When small: fades away once it takes up only a little of the screen as you zoom out. Each image on a map can also be set to always or never fade.

Backup & restore

A backup is one zip with everything: maps, drafts, images and their tiles, the planner and its reference images. It can be large.

Restoring replaces everything with the backup's contents and restarts the server. The current data is kept in a pre-restore-… folder inside the data volume until the next restore.

Planner

A to-do list of images to make. Use the upload button on an item to upload it: it goes into the library with the item's name and type, and the item is marked done. Items planned for a map show up first when you add images in that map's editor.
